# Inclusive Health Training — Module 1

Interactive compliance and legal foundations training for Inclusive Health.

This repository is being built as a lightweight, browser-based training application. The first release focuses on Module 1.1 (HIPAA, Washington privacy, 42 CFR Part 2, and minor privacy), with the remaining Module 1 courses scaffolded for expansion.

> **Training status:** Draft curriculum. Legal/regulatory content should be reviewed periodically against current HHS, OSHA, Washington State Department of Health, L&I, and RCW requirements.
